# Support

Use GitHub Issues for bug reports and support requests:

- [https://github.com/Sisyphean-a/vscode-stealth-chat/issues](https://github.com/Sisyphean-a/vscode-stealth-chat/issues)

Please include:

- VS Code version
- Extension version
- Active server URL pattern
- Whether the issue happens in `bubble` or `log` mode
- Relevant logs, screenshots, or reproduction steps
